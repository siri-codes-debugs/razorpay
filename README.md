# Razorpay Transaction Reconciliation System

A web-based transaction reconciliation system designed to help identify, investigate, and review transaction discrepancies through a simple dashboard.

## 🚀 Overview

This project provides a centralized interface for analyzing transactions and identifying reconciliation issues that require attention.

## ✨ Key Features

- **Transaction Reconciliation** — Analyze transaction records and identify discrepancies.
- **Issue Review** — Highlight transactions that require further investigation.
- **Investigation Panel** — View transaction-level information for detailed review.
- **Dashboard Metrics** — Quickly understand the reconciliation status.
- **Interactive Interface** — Clean and responsive dashboard for easier analysis.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
